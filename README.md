## 📌 About the Repository

Welcome to my **Compiler Construction Lab** repository!

This repository contains a collection of practical assignments completed as part of the Compiler Construction Laboratory course.

The main objective of these practicals is to understand the fundamental concepts of compiler design and gain hands-on experience with the different stages involved in translating source code into a form that a computer can understand.

The repository is organized into **10 practical assignments**, each maintained in its own folder.

## 🎯 Objectives

- Understand the fundamental architecture of a compiler.
- Explore different phases of compiler construction.
- Learn lexical and syntax analysis.
- Understand parsing techniques and grammar rules.
- Implement compiler-related algorithms through programming.
- Develop practical problem-solving and debugging skills.

## 🛠️ Technologies & Tools

The practicals use programming languages and compiler construction tools as required by individual assignments.

Common compiler construction technologies include:

- **C / C++** – Programming and implementation.
- **Lex / Flex** – Lexical analysis.
- **Yacc / Bison** – Syntax analysis and parsing.
- **GCC / G++** – Compilation.
- **VS Code** – Code editor.
- **Git & GitHub** – Version control and project management.

## 📖 Learning Outcomes

After completing these practical assignments, I aim to develop an understanding of:

- Compiler architecture and working.
- Lexical analysis and token recognition.
- Context-free grammars.
- Syntax analysis and parsing.
- Intermediate representations.
- Symbol tables and semantic analysis.
- The overall compilation process.
